# 需求分析

## 项目目标

本项目需要实现 16-bit split-sampling SAR ADC 的数字后端流程，覆盖前景电容权重校准、SAR 原始码流重构、系统级仿真验证和 FPGA 工程落地。

## 功能需求

1. 前景校准控制器应从低位可信权重开始，递归测量高位电容权重。
2. 校准控制器应输出 P/N 侧 DAC force 控制信号，并通过比较器反馈完成二分搜索。
3. 校准结果应通过 `w_wr_en/w_wr_addr/w_wr_data` 写回权重存储。
4. 重构模块应接收 `raw_bits` 与校准权重，输出 16-bit signed `adc_dout`。
5. 低 6 位权重是校准基准段，应由硬件复位路径稳定初始化，而不是由 testbench 层次化写入。
6. 仿真模型应提供确定性的电容权重表和比较器行为，便于回归分析。
7. 工程应保留 Vivado `.xpr` 可打开能力，避免整理目录时破坏项目相对路径。

## 非功能需求

- 可维护性：顶层必须有 README、MOC 和目录规范说明。
- 可追溯性：旧工程、大压缩包和生成物必须进入归档或忽略规则。
- 可验证性：至少保留系统级 testbench 和模块级 testbench 的入口说明。
- 兼容性：主 Vivado 工程路径保持不变，优先兼容 Vivado 2018.3。
- 版本管理：仓库只提交源码、约束、脚本和文档，不提交 `.runs/.sim/.cache/.hw` 等生成产物。
