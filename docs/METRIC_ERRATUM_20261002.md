# 频谱指标勘误与重新验证要求

## 已确认

物理 CDAC 再验证的历史 summary 中，理想满幅控制给出 SNR 95.639 dB、
SNDR 98.079 dB；回退控制也有 SNR 低于 SNDR 的情况。相同输入、带宽、
信号功率和噪声划分下，该关系不成立。

旧运行通过 ADCToolbox 返回字段直接发布指标。当前修改使用显式的相干单边谱：
直流排除、Nyquist 单计、谐波折返去重、同一个信号功率及噪声/失真分区。
ADCToolbox 的静态 INL/DNL 与外部正弦校准用途继续单独标注。

## 当前证据

数值检查包含已知谐波与非谐波、直流偏移、Nyquist、奇偶记录、理想量化及谐波别名。
自动检查结果属于数学指标实现，不是完整 ADC 再验证。

## 冻结结果处理

历史 JSON、CSV、PDF 与交付包保留原字节，作为旧实验记录；其中频谱数字标为待重算。
新实现没有把旧 SNR 人为提升到 SNDR，也没有根据汇总数字逆推未保留的波形。
重新发布前需在冻结依赖与种子下重跑完整 SAR、物理 CDAC、片上校准及噪声消融，
保存新原始输出、指标、环境、代码身份与差异报告。
