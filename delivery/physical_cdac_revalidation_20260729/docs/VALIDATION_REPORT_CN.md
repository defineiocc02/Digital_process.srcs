# 物理CDAC失配与片上自校准再验证报告

日期：2026-07-29
实验版本：`3.0`
详细正式报告：

## 1. 结论

在本项目 `6+4+5+5` 分段CDAC、8 fF单位电容、单位电容失配
`1.2% RMS`中心、普通转换噪声全部关闭的条件下，当前工程文件夹中的
P/N递归前台校准能够显著消除物理电容失配影响：

| 指标 | 未校准标称权重 | 当前校准 | 物理权重上限 |
| --- | ---: | ---: | ---: |
| 满幅SNDR中位数 | 58.327 dB | 95.256 dB | 97.139 dB |
| -1.72 dBFS SNDR中位数 | 56.525 dB | 93.577 dB | 95.428 dB |
| DNL max中位数 | 2.998 LSB | 0.968 LSB | 0 LSB |
| INL max中位数 | 68.697 LSB | 0.993 LSB | 0 LSB |
| 缺码中位数 | 991 | 0 | 0 |

因此，当前RTL算法对本模型定义的静态物理失配是有效的。但这仍是行为级
L2证据，不是PDK、AMS、PVT、PEX或硅片签核。

## 2. 理想16位门限与SRM问题

本轮把普通转换噪声和SRM统计误差分离：

| 理想路径 | SNDR |
| --- | ---: |
| 直接均匀16位量化 | 98.079 dB |
| 分段CDAC，不注入残差 | 95.087 dB |
| 分段CDAC，精确物理残差 | 98.079 dB |
| 分段CDAC，确定性期望SRM | 98.045 dB |
| 分段CDAC，随机22次SRM中位数 | 97.145 dB |

关闭SRM时下降不是因为脚本偷偷加入了采样噪声或正常比较器噪声，而是
20次冗余判决后仍存在未估计的亚码残差。精确残差路径恢复到98.079 dB，
证明SAR判决和Q8重构数学闭合；22次随机SRM相对确定性路径的剩余损失来自
有限二项统计。

## 3. 满幅尾部与修复候选

当前校准满幅最差芯片为55.619 dB，原因是校准权重总和偏大导致输出rail
clipping，而该芯片在回退输入下仍有93.495 dB。对称总和归一化虽然能修复
该芯片，但当比例大于1时会放大另一些芯片并制造新饱和。

本轮新增分析候选：

```text
guard_scale = min(1, nominal_weight_sum / calibrated_weight_sum)
```

它只允许缩小，不允许放大。正式512芯片结果：

- 当前校准满幅 `>=90 dB`：504/512；
- 对称总和归一化：510/512；
- 单边余量保护：512/512；
- 单边保护满幅最差：93.129 dB。

该候选不改善回退条件下的相对权重误差，不能称为新的校准算法，也尚未
加入核心RTL。

## 4. 物理失配定义

本轮不是对最终权重直接施加任意3%误差，而是先抽样物理位电容、桥接电容、
节点寄生和比较器输入电容，再解四节点电容矩阵。由 `N` 个单位电容组成的
电容采用：

```text
sigma_rel = 1.2% / sqrt(N)
```

512颗芯片中，有效权重相对误差RMS中位数为0.696%，最大绝对有效权重误差
中位数为1.665%。这些中心来自项目归档MATLAB，不是工艺厂PDK数据。

## 5. 校准原理

论文P/N双方向测量为：

```text
D+ = +Wk + Vos + n+
D- = -Wk + Vos + n-
W_hat = (D+ - D-) / 2
```

失调 `Vos` 被消除。当前RTL通过相反的比较极性把两方向结果编码成正幅值，
等效地累加 `M+ + M-` 后除以 `2*AVG_LOOPS`。`AVG_LOOPS=32`意味着32个
P/N对、64次方向测量，独立噪声标准差理论上缩小到1/8。

校准从bit 6递归到bit 19；bit 18和bit 19使用强制保护位压缩顶板摆幅，并
在数字域补回保护权重。

## 6. 未复现边界

本Python模型尚未包含：

- split-sampling的Cs/CDAC/flash跟踪及VCM切换时序；
- 2-bit flash首次粗量化；
- AZ预放大器噪声混叠与带宽；
- 开关导通电阻、电荷注入、clock feedthrough、kickback；
- 参考记忆与建立误差；
- PDK失配、PVT、PEX和版图相关性。

所以本轮证明的是数字算法对物理权重失配的处理能力，不是完整论文芯片复现。

## 8. 维护建议

1. 保持当前三块核心RTL为算法基线。
2. 单边余量保护如需进入RTL，必须单独定义量程、接口、定点实现和TB。
3. 下一阶段应建立AMS/Verilog-A顶层，逐相位复现论文Fig.6的SS、VCM、flash、
   AZ、SAR和SRM时序。
4. 用目标工艺PDK与版图提取数据替换项目MATLAB失配中心。
